# Alfa Hackathon — AI-агент для персонализированной банковской аналитики

## О проекте

**Alfa Hackathon** — проект интеллектуального помощника для анализа клиентских профилей и финансовых новостей. Система использует AI для формирования персонализированных аналитических рекомендаций на основе доступной информации о клиентах и актуальных новостных данных.

Проект объединяет обработку новостей, работу с клиентскими профилями, языковую модель и веб-интерфейс для представления результатов анализа.

## Основные возможности

- **AI-агент** — анализирует клиентский профиль и формирует персонализированные рекомендации.
- **Сбор финансовых новостей** — получает и обрабатывает публикации из информационных источников.
- **Персонализация** — использует данные клиентских профилей для отбора релевантных событий.
- **Интеграция с языковой моделью** — взаимодействует с LLM через API.
- **Банковская аналитика и RAG** — предусмотрена работа с дополнительными аналитическими материалами.
- **Веб-интерфейс** — отображает результаты анализа и позволяет взаимодействовать с данными через backend API.

## Архитектура

Проект состоит из нескольких основных компонентов:

| Компонент | Назначение |
|---|---|
| `agent.py` | Логика AI-агента и формирование аналитических результатов |
| `news_parser.py` | Сбор и обработка финансовых новостей |
| `bank_rag.py` | Компонент работы с банковскими материалами и RAG |
| `server.py` | Backend на FastAPI, предоставляющий API для frontend |
| `static/` | Веб-интерфейс: HTML, CSS и JavaScript |
| `client_profiles.json` | Данные клиентских профилей |
| `insights.json` | Сгенерированные результаты анализа |
| `requirements.txt` | Зависимости Python |
| `Dockerfile` | Конфигурация контейнеризации приложения |
| `docker-compose.yml` | Конфигурация запуска сервисов через Docker Compose |

## Требования

Для локального запуска необходимы:

- Python 3.12 или совместимая версия;
- Git;
- доступ к API языковой модели;
- зависимости, перечисленные в `requirements.txt`.

Для компонентов обработки документов могут потребоваться дополнительные системные зависимости, включая Tesseract OCR.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/nelya077/alfa-hakaton.git
cd alfa-hakaton
```

### 2. Создание виртуального окружения

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Если активация окружения заблокирована политикой PowerShell, можно запускать Python напрямую через `.venv\Scripts\python.exe`.

### 3. Установка зависимостей

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` на основе `.env.example` и заполните необходимые значения:

```env
ALFA_LLM_API_KEY=your_api_key
ALFA_LLM_BASE_URL=your_api_base_url
```

Укажите действительные параметры API, предоставленные для проекта.

**Важно:** файл `.env` содержит секретные настройки и не должен публиковаться в GitHub.

### 5. Проверка подключения к языковой модели

Если в репозитории присутствует `call_llm.py`, соединение можно проверить командой:

```powershell
python .\call_llm.py --ping
```

### 6. Сбор финансовых новостей

Для загрузки новостей за последние семь дней:

```powershell
python .\news_parser.py --db .\news.db --days 7
```

Результаты сохраняются в локальную базу данных новостей.

### 7. Запуск AI-агента

Пример запуска для клиента с идентификатором `U_9250`:

```powershell
python .\agent.py --client U_9250 --out insights.json
```

В результате формируется файл `insights.json` с результатами работы агента.

Для другого клиента укажите соответствующий идентификатор, присутствующий в данных проекта.

### 8. Запуск веб-приложения

Запустите backend:

```powershell
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Откройте приложение в браузере:

**http://127.0.0.1:8000**

Проверить доступность backend можно по адресу:

**http://127.0.0.1:8000/health**

## API

Backend предоставляет следующие основные маршруты:

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/health` | Проверка состояния приложения |
| GET | `/api/clients` | Получение списка клиентов |
| GET | `/api/feed?client_id=...` | Получение ленты событий для клиента |
| GET | `/api/card/{event_id}` | Получение подробной информации о событии |

## Конфиденциальность и безопасность

- Не публикуйте API-ключи и другие секреты.
- Перед загрузкой клиентских данных проверьте, допустимо ли их раскрытие.
- Используйте обезличенные или тестовые данные для публичной демонстрации.
- Сгенерированные файлы, локальные базы данных и индексы следует добавлять в репозиторий только при необходимости.

## Ограничения

Результаты языковой модели могут содержать ошибки и требуют проверки. Сгенерированные рекомендации являются аналитическими результатами системы и не должны автоматически рассматриваться как подтверждённые финансовые факты или индивидуальная инвестиционная рекомендация.
